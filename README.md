# AuraPh

Фото товаров магазина Aura для загрузки на Ozon по ссылке.

Файлы складываются сюда автоматически скриптом выгрузки (`tools/ozon/ozon.py build`) из рабочего проекта.
Папка = артикул товара, в имени файла хэш содержимого. Старые версии не удаляются: Ozon мог ещё не скачать их по прежним ссылкам.

Здесь только готовые JPG для карточек. Исходники, данные и ключи сюда не кладутся.
